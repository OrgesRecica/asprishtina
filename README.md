# KB AS Prishtina

Editorial multi-page React/Vite web app for AS Prishtina basketball. It includes Home, Standings, Roster, and Matches routes with verified 2026/27 federation data.

## Run

```bash
npm install
npm run dev
```

## Data notes

- Roster, licenses, player portraits, schedule and results: Kosovo Basketball Federation team page.
- Club mark: public `@kb.asprishtina` Instagram profile image.
- The 15 November result (AS Prishtina 100–92 Fushë Kosova) is newer than the federation's cached standings table. The UI therefore labels the adjusted table as provisional.
